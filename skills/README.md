# Skills moved to boutique-openclaw-skills

This installer repository no longer vendors default skills, generated skill guides, or local skill manifests.

- Default China source: https://gitee.com/leecyno1/boutique-openclaw-skills.git
- GitHub fallback: https://github.com/leecyno1/boutique-openclaw-skills.git
- Installed runtime target: `~/.openclaw/skills`

Use `openclaw-setup config skills --tier low|medium|high` to install from the boutique repository or its local cache.
